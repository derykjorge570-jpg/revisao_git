Principais atalhos do Visual Studio Code

Atalhos gerais

  • Ctrl + S: Salvar arquivo
  • Ctrl + P: Abrir arquivo rapidamente
  • Ctrl + Shift + P: Abrir a paleta de comandos
  • Ctrl + W: Fechar editor
  • Ctrl + Shift + W: Fechar janela

Edição

  • Ctrl + C: Copiar
  • Ctrl + V: Colar
  • Ctrl + X: Recortar
  • Ctrl + Z: Desfazer
  • Ctrl + Y: Refazer
  • Ctrl + F: Pesquisar

Terminal

  • Ctrl + `: Abrir o terminal
